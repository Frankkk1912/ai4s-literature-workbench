AI4S Literature Workbench 配置向导

此管理页只在本机 loopback、无 OAuth 的 HTTP 模式中启用。

1. 配对本次会话

从启动 MCP 的终端复制一次性配对码。配对码只可兑换一次，且不会进入 URL 或日志。

2. 校验并保存凭证

已存凭证永不回显；状态只显示是否存在与来源。

3. Zotero Desktop XPI

本轮不核验安装状态。构建 XPI 后，在 Zotero Desktop 打开 Tools → Add-ons，齿轮菜单 → Install Add-on From File…，选择 literature-metrics/dist/literature-metrics-<version>.xpi。

凭证暴露边界

  1. 浏览器仅以本机 loopback POST body 提交凭证；payload 在用户自己的 DevTools 中可见，这是固有边界。
  2. Zotero 官方校验请求通过 Zotero-API-Key Header 携带凭证。
  3. PubMed / EasyScholar 官方 HTTPS 校验请求按其接口设计，以 api_key / secretKey 查询参数携带凭证。

本地页面 URL、地址栏、链接、服务日志、响应、错误与状态报告不会包含明文凭证或含凭证的官方请求 URL。
