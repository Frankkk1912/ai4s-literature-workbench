# AI4S Literature Workbench for DeepSeek Harness

Zotero and full-text tools plus the literature skills (research, Zotero manager, writing, and first-run setup), packaged for DeepSeek Harness.

Install it from the Plugins page or with `dsh plugin add`; the steps, and what has and has not been tested, are in [INSTALL.md](https://github.com/Frankkk1912/ai4s-literature-workbench/blob/main/INSTALL.md).

This package carries ready-to-run copies of the tools, so it needs nothing built or installed beyond DeepSeek Harness itself. Keys are optional and are entered on a local setup page, never in chat. Source and licence: https://github.com/Frankkk1912/ai4s-literature-workbench
