# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Use [GitHub Private Vulnerability Reporting](https://github.com/Frankkk1912/ai4s-literature-workbench/security/advisories/new) to open a private advisory, or open a regular issue with no sensitive details if that channel is unavailable.

We will acknowledge the report as soon as practical and coordinate a fix and disclosure with you.

## Scope

This repository is a local, single-user workbench (skills, MCP runtimes, a Zotero XPI, and a local configuration wizard). It listens on localhost only and stores optional API credentials in local files excluded from version control (see `.gitignore`).

## Supported Versions

Only the latest release on `main` is supported.
